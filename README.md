# CINESCOPE — Movie Rating Analysis + IMDb Sentiment

VS Code / Streamlit. The original movie analysis, numerical rating predictor, model comparison and dark UI are preserved. A new **Review sentiment** page is added for classifying written reviews.

## Setup on Windows

Extract the project ZIP, then open the directory containing `app.py` in VS Code.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Then visit http://localhost:8501.
Streamlit link - https://cinescope-cbjmnsje2yzklcqikuarao.streamlit.app

## Train the sentiment model in Colab

1. Upload `CINESCOPE_IMDb_Sentiment_Training.ipynb` to Colab.
2. Run **Runtime → Run all**. KaggleHub downloads the IMDb dataset automatically.
3. Read the actual accuracy and other test metrics. The result is not hardcoded; **90% is a goal, not a guarantee**.
4. Colab downloads `cinescope_sentiment_assets.zip`.
5. Extract all six files (`sentiment_model.pkl`, `sentiment_metrics.json`, `sentiment_comparison.csv`, `sentiment_confusion_matrix.csv`, `sentiment_roc.csv`, `sentiment_terms.csv`) into the same directory as `app.py`.
6. Refresh **Review sentiment** in Streamlit.

## Original XGBoost predictor on Windows

The original `movie_rating_model.pkl` sometimes fails to deserialize on Windows. If you already have working files, copy `rating_xgboost.json` and `rating_preprocessor.pkl` from your current working project folder into this folder. Otherwise follow `MODEL_FIX.md` and run `colab_portable_export.py` in your original movie-rating Colab notebook. All non-predictor pages, including Review sentiment, work without those two files.

## Project files

- `app.py`: single-file Streamlit application
- `movie_dashboard_data.csv`, `regression_comparison.csv`, `classification_comparison.csv`, `model_info.json`: original SI Lab dashboard files
- `movie_rating_model.pkl`, `movie_classification_model.pkl`: original trained pipelines (see Windows note)
- `CINESCOPE_IMDb_Sentiment_Training.ipynb`: second Colab notebook
- `sentiment_*`: generated by that notebook, not included until trained

The numerical movie rating regression and IMDb review sentiment classification are separate ML tasks. Their evaluation scores must not be compared as if they represented the same prediction target.

Original IMDb dataset: https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews
